FilmCraft for Agents

A real video editor that AI agents can actually drive.

FilmCraft is a clean-room, Premiere-class non-linear editor written in pure Rust. This distribution wraps its headless engine so an agent on Linux, Windows, or macOS can cut, caption, transition and export video — one JSON file in, an mp4 out.

Install in one line GitHub repo Binaries (Releases) See a recipe

01Install

One command puts filmcraft-cli (the engine) and fcedit (the agent tool) on PATH. No ffmpeg, no GPU, no window needed.

curl -fsSL https://raw.githubusercontent.com/jokedud/filmcraft-agent/main/agent/install.sh | sh
powershell -ExecutionPolicy Bypass -c "irm https://raw.githubusercontent.com/jokedud/filmcraft-agent/main/agent/install.ps1 | iex"
docker build -f agent/Dockerfile -t fcedit .
docker run -p 8321:8321 -v $PWD/media:/media fcedit
# POST recipes to http://localhost:8321/recipe
git clone https://github.com/jokedud/filmcraft-agent && cd filmcraft-agent
cargo build --release -p filmcraft-cli
# binary at target/release/filmcraft-cli; agent tool is agent/fcedit.py

fcedit build

Declarative recipe → exported video. Named clips, auto-append timeline, transitions, effects, captions, keyframes.

fcedit serve

A persistent editing session over HTTP — POST /recipe, /run, /batch, /frame, GET /inspect.

filmcraft-cli mcp

A full MCP server on stdio. Plug it into Claude Code, Devin, or any MCP client and the tools appear.

02The recipe format

One JSON document describes media, timeline, styling and export. fcedit build compiles it to engine commands against a live session — clip ids resolve by name.

{
  "sequence": {"width": 1920, "height": 1080, "fps": 30},
  "media": {"a": "/abs/intro.mp4", "song": "/abs/music.mp3"},
  "captions": {"format": "Subtitle", "style": {"size": 42, "anchor": "bottom"}},
  "timeline": [
    {"op": "place", "src": "a", "in": 2, "out": 8, "name": "intro"},
    {"op": "place", "src": "a", "in": 12, "dur": 4},          // auto-appends
    {"op": "audio", "src": "song", "at": 0, "track": "A2", "dur": 10},
    {"op": "transition", "clip": "intro", "effect": "cross_dissolve", "frames": 24, "edge": "out"},
    {"op": "text", "content": "MADE BY AN AGENT", "at": 0.5, "dur": 4, "position": [960, 540], "size": 120},
    {"op": "effect", "clip": "#1", "effect": "gaussian_blur", "params": {"blurriness": 30}},
    {"op": "speed", "clip": "intro", "speed": 200},
    {"op": "gain", "clip": "intro.audio", "db": -6},
    {"op": "caption", "text": "hello world", "at": 1, "dur": 2},
    {"op": "marker", "at": 4, "name": "beat drop"}
  ],
  "export": {"path": "out.mp4", "format": "h264", "crf": 20, "burnCaptions": true}
}
fcedit build recipe.json --verbose
# → out.mp4 (h264 1080p, captions burned in)

04Wire it to your agent

MCP (Claude Code, Devin…)

{"mcpServers": {"filmcraft":
  {"command": "filmcraft-cli", "args": ["mcp"]}}}

Tools: command_run, command_batch, command_list, doc_inspect, media_import, render_frame, plus UI-driving tools in bridge mode.

HTTP (any device, any language)

fcedit serve --port 8321

curl -X POST localhost:8321/recipe \
  -H 'Content-Type: application/json' -d @recipe.json

Also POST /run, /batch, /frame (PNG), GET /inspect, /commands. Or ship the whole thing as the Docker image.

Skill file

Drop agent/SKILL.md into your agent's skills — it documents install, the recipe schema, clip refs, and the command cookbook.

Raw JSONL / CLI

filmcraft-cli exec timeline.place '{"item":8,"track":"V1","time":0}'
filmcraft-cli run script.jsonl --save-as edit.fcproj
filmcraft-cli export out.mp4 --project edit.fcproj --format h264

Every command is a shell call; projects persist as .fcproj files.

05What you get

  • The whole engine, headless. 700+ commands: multi-track timeline, linked A/V clips, ripple/roll/slip/slide trims, transitions, effects, keyframes, captions (608/708/Subtitle/Teletext), markers, nested sequences, interchange (EDL/OTIO/FCP-XML/AAF).
  • Real media in, real media out. h264/HEVC/ProRes/DNxHR/APV/MJPEG encode, MXF Op-1a/Op-Atom, image sequences, WAV/AIFF/AAC/FLAC audio. Decode for the formats you'd feed an editor.
  • No GPU, no ffmpeg. Pure-Rust decoders and encoders; CPU compositor (GPU optional). It runs on a tiny VPS or a laptop.
  • Never crashes. The upstream rule: malformed media, bad params, corrupt projects return actionable errors — never a panic, never lost work.
  • A desktop app too. The same engine drives the FilmCraft GUI; agents can attach to a live editor over the control channel (--bridge) and click, drag, and screenshot it.
